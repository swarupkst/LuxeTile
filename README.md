# 🧱 LuxeTile

A modern and responsive tile gallery web application built with **Next.js**. Users can browse beautiful tiles, search tiles by name, view detailed information and manage their profile with secure authentication.

## 🌐 Live Website

https://luxe-tile.vercel.app

---

## 🎯 Project Purpose

The purpose of this project is to create a visually appealing tile gallery platform where users can:

- Explore premium tile collections
- Search and view tile details
- Authenticate securely using email/password or Google login
- Manage their personal profile
- Experience a fully responsive modern UI

This project was developed as an assignment project using modern full-stack web technologies.

---

## ✨ Key Features

- 🔐 Authentication with BetterAuth
- 🔑 Google Social Login
- 👤 User Registration & Login System
- 🖼️ Featured Tiles Section
- 🔍 Search Functionality for Tiles
- 📄 Single Tile Details Page
- 👤 My Profile Page
- ✏️ Update User Information Feature
- ⚡ Loading Spinner During Data Fetching
- ❌ Custom Not Found Page
- 📱 Fully Responsive Design
- 🎞️ Interactive Slider using SwiperJS
- 🌈 Modern UI with Tailwind CSS & DaisyUI
- 🔒 Environment Variables for Secure Configurations

## 🚀 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/your-repo-name.git
```

Go to the project directory:

```bash
cd your-repo-name
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env.local` file and add your environment variables:

```env
MONGODB_URI=your_mongodb_uri
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
BETTER_AUTH_SECRET=your_secret
BETTER_AUTH_URL=http://localhost:3000
```
